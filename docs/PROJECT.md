# Instructions

- **🎯 Stack**
    
    Use **React + Next.js** for the front end and **Supabase** (Postgres, Storage) for the back end.
    
- **🚀 Deployment**
    
    Host the live site on **Vercel** and share the public URL.
    
- **🛠️ Core Features**
    1. **Create Listing** – Upload a photo and enter title, description, price, email, and category.
    2. **Browse & Search** – Display listings in grid or list view with category tabs.
    3. **Listing Detail Page** – Show image, full details, and a **“Message Seller”** button (saves the buyer's message in Supabase; sending a real email is a bonus).


### **✅ What Counts as Done**

You pass if these four things work on your live site:

1. A visitor can create a listing with a photo, title, description, price, email, and category, and it is saved in Supabase.
2. The home page shows all listings, with category tabs to filter them.
3. Each listing has its own page with the photo and full details.
4. **Message Seller** saves the buyer's message in Supabase.

That's it. No login is needed. Bonus (optional): keyword search, and sending the seller a real email when a message arrives.
